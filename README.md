# C++ modules

The ten C++ modules (CPP00 to CPP09) of the École 42 (Brussels) curriculum, written in C++98.

| Module | Topics |
|---|---|
| CPP00 | Namespaces, classes, member functions, stdio streams |
| CPP01 | Memory allocation, pointers to members, references, switch |
| CPP02 | Ad-hoc polymorphism, operator overloading, Orthodox Canonical Form |
| CPP03 | Inheritance |
| CPP04 | Subtype polymorphism, abstract classes, interfaces |
| CPP05 | Exceptions |
| CPP06 | C++ casts |
| CPP07 | Templates |
| CPP08 | Templated containers, iterators, algorithms |
| CPP09 | STL |

Each exercise has its own folder and Makefile:

```bash
cd CPP00/ex00 && make
```
